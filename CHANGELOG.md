## [0.1.0] - 2026-05-12

### Added
- Initial release with 16 skills:
  - **Clinical writing**: `clinical-paper-writing`, `medical-imaging-methods`, `clinical-statistics-reporting`, `cover-letter-medical`, `response-to-reviewers`
  - **Funding**: `grant-writing-spanish`, `grant-writing-eu`
  - **Senior engineering**: `senior-scientific-code-review`, `scientific-code-craft`, `scientific-documentation`, `research-code-maturation`, `scientific-debugging`
  - **Domains**: `embedded-medical-wearable`, `oss-contribution`, `oss-project-setup`, `bioinformatics-pipelines`
- Install script (`install/install.sh`) that sets up `~/tools/biomed-skills/` and slash commands in `~/.claude/commands/`.
- Documentation: README, quickstart, contributing guidelines.
- CI workflow validating skill frontmatter.
